# Modules

1. Authentication: registration, login, JWT, password hashing, RBAC.
2. Users/Organizations: profiles, organization membership.
3. Subscription: plans, limits, start/expiry.
4. Payment: checkout, payment records, Razorpay webhook, idempotency.
5. API Keys: create, revoke, rotate, usage.
6. Tenant: tenant profile and history.
7. Property: property records.
8. Lease: rent amount, dates, due day.
9. Consent: request, approve, reject, revoke, expiry, audit.
10. Verification: request lifecycle and orchestration.
11. Transaction: CSV upload, normalization, storage.
12. Payment Matching: month grouping, amount/date matching, split/duplicate detection.
13. AI: model training, persistence, inference, metrics, model version.
14. Report: standardized JSON/report data and access control.
15. Notification: payment/subscription/verification emails.
16. Admin: users, payments, subscriptions, verifications, review queue.
17. Audit: append-only activity log.
