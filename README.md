# Rent Verification API — Antigravity Build Pack

Fixed stack:
- Frontend: React + TypeScript + Vite + Tailwind CSS
- Backend: Python + FastAPI + Pydantic + SQLAlchemy
- Database: PostgreSQL
- AI/ML: Scikit-learn only (Random Forest + Isolation Forest)
- Cache/jobs: Redis + Celery
- Auth: JWT + RBAC
- Payment: Razorpay
- Email: SMTP
- API: REST + JSON + OpenAPI/Swagger
- Storage: local for development, S3 for production
- Containers: Docker + Docker Compose
- Cloud: AWS
- Testing: Pytest + Playwright + Postman

MVP: CSV rental transaction upload; no live banking integration.
