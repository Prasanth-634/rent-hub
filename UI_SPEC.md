# UI Specification

Public: Landing, Pricing, Login, Register.
Customer: Dashboard, Subscription, API Keys, Tenants, Properties, Leases, Verification Requests, Verification Detail, Reports, API Docs.
Tenant: Requests, Request Detail, Consent, Upload, Status.
Admin: Dashboard, Users, Plans, Payments, Verifications, Review Queue, Audit Logs, Health.

UI requirements: responsive, accessible labels, loading/error/empty states, confirmation dialogs, no secrets in URLs.
